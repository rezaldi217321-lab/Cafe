# RZD SKY CAFÉ
Website konsep 3D responsif untuk café dua lantai.

## Isi konsep
- Lantai atas: café indoor, kaca lebar, balkon dan pergola.
- Lantai bawah: parkir kendaraan serta area duduk outdoor.
- Palet: Ivory Cream, Charcoal/Silver Dark, Forest Green, Warm Bronze.
- Model 3D memakai Three.js dan OrbitControls dari CDN. Koneksi internet diperlukan saat membuka website.

## Deploy ke GitHub Pages
1. Buat repository baru di GitHub, misalnya `rzd-sky-cafe`.
2. Upload `index.html` dan `README.md` ke root repository.
3. Buka Settings > Pages.
4. Pada Build and deployment pilih Deploy from a branch, branch `main`, folder `/ (root)`, lalu Save.

## Deploy ke Cloudflare Pages
1. Push repository ke GitHub.
2. Di Cloudflare Dashboard buka Workers & Pages > Create > Pages > Connect to Git.
3. Pilih repository `rzd-sky-cafe`.
4. Framework preset: None. Build command kosong. Build output directory: `/`.
5. Klik Save and Deploy.

Catatan: ini prototipe visual/website, bukan gambar kerja arsitektur atau perhitungan struktur. Minta arsitek/insinyur memeriksa fondasi, kolom, bentang, akses parkir, ventilasi, proteksi kebakaran, dan keselamatan sebelum pembangunan nyata.
